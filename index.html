19/20 Projeto final · Parceria ARTE, I.P. (ex-AMA) Capstone · Partnership with ARTE, I.P. Set 2025 – Ago 2026 Equipa de 2Team of 2

Automação NetDevOps closed-loop para VPN IPsec sobre MPLS Closed-loop NetDevOps automation for IPsec VPN over MPLS

Prova de conceito num laboratório virtualizado (VMware, FortiOS 7.6) que deteta, diagnostica e corrige falhas numa rede Hub-and-Spoke sem intervenção humana, e escala para o operador o que não pode corrigir. Proof of concept in a virtualised lab (VMware, FortiOS 7.6) that detects, diagnoses and fixes faults in a hub-and-spoke network without human intervention, and escalates what it cannot fix to the carrier.

ProblemaProblem

Em redes do Estado com túneis IPsec sobre MPLS, um desvio de configuração (gateway, seletores da Phase 2, políticas de firewall) causa quebras silenciosas. A triagem manual demora 15 a 30 minutos. In public-sector networks running IPsec tunnels over MPLS, configuration drift (gateway, Phase 2 selectors, firewall policies) causes silent outages. Manual triage takes 15 to 30 minutes.

O meu contributoMy contribution

  • Scripts de remediação em Python / Netmiko
  • Integração com a REST API CMDB do FortiOS
  • Modelo de dados no NetBox como fonte de verdade
  • Nós de decisão no n8n (pre-check ICMP, diagnóstico)
  • Remediation scripts in Python / Netmiko
  • FortiOS CMDB REST API integration
  • NetBox data model as source of truth
  • Decision nodes in n8n (ICMP pre-check, diagnosis)

ResultadoOutcome

Em 24 incidentes injetados (10 cenários), todas as 15 falhas lógicas foram corrigidas automaticamente. As falhas físicas foram escaladas ao operador sem tentativas inúteis de SSH/API. Across 24 injected incidents (10 scenarios), all 15 logical faults were fixed automatically. Physical failures were escalated to the carrier without futile SSH/API attempts.
